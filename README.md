# اوقات شرعی — PWA

## روش انتشار رایگان روی GitHub Pages

### مرحله ۱: ساخت اکانت GitHub
به آدرس github.com بروید و اکانت رایگان بسازید.

### مرحله ۲: ساخت Repository
- روی "New repository" کلیک کنید
- نام: `oghat-sharii`
- گزینه "Public" را انتخاب کنید
- "Create repository" بزنید

### مرحله ۳: آپلود فایل‌ها
- روی "uploading an existing file" کلیک کنید
- همه فایل‌های این پوشه را drag & drop کنید
- "Commit changes" بزنید

### مرحله ۴: فعال‌سازی GitHub Pages
- به Settings > Pages بروید
- Source: "Deploy from a branch"
- Branch: main / (root)
- Save

### لینک نهایی شما:
`https://[username].github.io/oghat-sharii/`

این لینک را می‌توانید برای دوستانتان بفرستید.

## فایل‌ها
- `index.html` — صفحه اصلی
- `oghat_manifest.webmanifest` — تنظیمات PWA
- `oghat_sw.js` — Service Worker (آفلاین)
- `oghat_icon.svg` — آیکون اصلی
- `icon-192.png` — آیکون اندروید
- `icon-512.png` — آیکون بزرگ
- `apple-touch-icon.png` — آیکون iOS
